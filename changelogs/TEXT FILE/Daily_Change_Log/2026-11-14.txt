6. Face Recognition Pipeline Enhancement & Biometric Hardening:
   - Git Feature Branch: `feature/smartattend-face-recognition-enhancement`.
   - Rollback Backup: Stored at `backup_pre_face_enhancement/` with clean pre-modification snapshots.
   - Multi-Sample Pose Registration (`html/register.html`, `backend/register.js`):
     * Replaced single-sample enrollment with a 3-pose sequential capture workflow:
       - Pose 1: Neutral Front-Facing view.
       - Pose 2: Slight Left (~15°) head turn.
       - Pose 3: Slight Right (~15°) head turn.
     * Enforced 4-stage client-side biometric quality gates:
       1. Single-face invariant (`detectAllFaces.length === 1`).
       2. Minimum face resolution ($110\text{px} \times 110\text{px}$).
       3. Photometric illumination gate ($40 \le \text{luma} \le 230$).
       4. 68-landmark yaw symmetry validation for angle adherence.
     * Version 2 polymorphic biometric schema stored in `students.Face_Encoding`:
       `{ version: 2, count: 3, enrolled_at: '...', templates: [[...128], [...128], [...128]] }`.
   - Classroom Live Recognition Hardening (`html/dashboard1.html`):
     * Polymorphic descriptor loader: Seamlessly loads legacy 128-element Float32 arrays and v2 multi-template arrays.
     * Threshold calibration: Lowered Euclidean distance threshold from `0.9` (excessively permissive) to calibrated `0.45`, eliminating false acceptances and wrong-student attendance marking.
     * Live detector resolution: Increased TinyFaceDetector `inputSize` from `128` to `224` (with `scoreThreshold: 0.55`), expanding detectable range by 2.5x across lecture halls.
     * Multi-frame temporal consensus: Requires 3 matching frames within a sliding 8-frame window before confirming presence (`student.detected = true`), avoiding momentary false positive triggers.
     * Preserved gender annotation (`[M]` / `[F]`), on-leave badges, late minutes calculation, and manual professor override toggles.
   - Biometric Security & RBAC Enforcement (`server/server.js`):
     * Added `'save_encoding'` and `'get_encoding'` to `RBAC_RULES` restricted strictly to `professor` and `admin`.
     * Protected generic `update` endpoint against non-faculty modifications to `Face_Encoding`.
     * Enforced strict vector payload validation (128-float arrays, finite numbers only).
