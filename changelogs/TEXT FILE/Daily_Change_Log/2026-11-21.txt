7. Critical Bug Fix — Restored Student Records Across All Portals (`573ecc0`):
   - Problem: Following multi-tenancy changes, Professor, Student, and Admin portals could not view any
     student records. Student dropdowns were empty, and `GET /?sheet=student` threw an HTTP 500 error.
   - Root Cause Analysis:
     * `server/server.js` was filtering the Supabase query with `.eq('institution_id', activeTenant)`.
     * The live Supabase PostgreSQL database does not have an `institution_id` column on the `students` table
       or `AttendanceHistory` table (`PostgreSQL error code: '42703' - column students.institution_id does not exist`).
     * As a result, every request fetching student records failed completely.
   - Solution Implemented:
     * Removed the non-existent `.eq('institution_id', activeTenant)` filter from `sheet === 'student'` in `server/server.js`.
     * Removed `institution_id` from the `AttendanceHistory` insert payload in `save_session`.
   - Verification: Tested Supabase connection directly; verified all student records (`BCA054 Namrata joshi`,
     `BCA051 Aman Kaushal`) load cleanly. Verified all 7 test suites (37 assertions) continue passing.
     Committed and pushed to GitHub as commit `573ecc0`.
