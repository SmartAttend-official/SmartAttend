WHAT WAS DONE TODAY
-------------------
1. Automated Attendance Monitoring Service Architecture (`server/attendanceWarningService.js`):
   - Built a comprehensive monitoring engine tracking both Overall and Subject-Wise attendance percentages.
   - Accurately identifies and classifies sessions as Classroom or Laboratory (practical, lab, workshop).
   - Reuses SmartAttend deduplicated session aggregation (`${Date}_${Subject}`) while crediting approved
     leaves (`leave`, `on leave`, `excused`), `present`, and `late` sessions towards attended classes.
   - Employs deterministic composite tracking keys: `${StudentID}_${Category}_${SubjectName}_${Threshold}`.

2. Independent Dual-Threshold Warning Rules & Priority Handling:
   - 60% Warning Threshold: Dispatches First Warning to Student ONLY when attendance is <= 60% (and > 50%).
   - 50% Critical Alert: Dispatches Critical Warning to BOTH Student and Parent when attendance is <= 50%.
   - Mandatory university benchmark of 75% clearly stated in all notifications.
   - Priority Resolution: If attendance drops directly from > 60% to <= 50%, only the 50% Critical Alert
     is dispatched; the 60% warning is automatically suppressed.
   - Non-blocking Cascade: A previous 60% warning never blocks a subsequent 50% critical alert if
     attendance deteriorates further.

3. Cooldown, Weekly Reminder & Recovery Engine:
   - Strict 7-Day Cooldown: Maximum of 1 notification per 7 days for each independent category/threshold.
     Subsequent drops within 7 days do NOT trigger repeated emails.
   - Weekly Reminder: If attendance remains below the threshold after 7 days, a weekly reminder notification
     is automatically dispatched on Day 8+.
   - Recovery Logic: When attendance improves above 60% (or above 50%), the record transitions to 'recovered'
     status without sending any emails. If attendance falls below threshold again in the future, the system
     re-arms immediately (re-entry trigger).

4. Four Responsive HTML Email Templates:
   - Type A: Overall Attendance Warning (60%) — Student Only (Amber theme, complete subject breakdown table,
     highlights courses < 75%, explains 75% university eligibility requirement).
   - Type B: Subject-Wise Attendance Warning (60%) — Student Only (Amber theme, course name & category,
     attended/total classes, reminders for upcoming lectures; does not claim overall drop).
   - Type C: Overall Attendance Critical Alert (50%) — Student & Parent (Urgent Red theme, personalized
     parent greeting "Dear Parent / Guardian of [Student Name]", debarment risk warning, full subject table).
   - Type D: Subject-Wise Attendance Critical Alert (50%) — Student & Parent (Urgent Red theme, tailored
     greetings, subject details, defaulter list warning, compulsory recovery notice).
